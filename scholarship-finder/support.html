Support

Need help using Scholarship Finder? The best way to get help is to describe the issue in the ChatGPT conversation where you are using the plugin, including the scholarship or query involved and what went wrong.

Before reporting an issue
  • Check the official scholarship provider page for the latest deadline and eligibility.
  • If a result looks outdated or incorrect, ask Scholarship Finder to verify it again using official sources.
  • For a specific scholarship, include its name and country so the result can be checked accurately.
